Read `AGENTS.md` first — this Next.js (16.2) has breaking changes; check `node_modules/next/dist/docs/01-app/` before using any Next API (e.g. `proxy.ts` not middleware; `after()`; `<ViewTransition>`).

## Process
- Branch `claude/zen-wright-dca3b6`. **Never commit, never switch branches, never push** — the orchestrator stages explicit paths and commits.
- Other agents work in the same tree concurrently. Edit ONLY files you own (your task lists them). Typecheck errors in files you don't own are not yours — ignore them.
- Do NOT run `next build` (it clobbers `.next` while others run servers). Use `npx tsc --noEmit`, `npx eslint <your files>`, `npx vitest run`. For visual checks run `npx next dev -p <your own port>` (pick 31xx) and kill it afterwards. Chromium + Playwright are preinstalled: `require('playwright')`, `chromium.launch()` with no options; never install browsers.
- Scratchpad for screenshots/temp: `/tmp/claude-0/-home-user-devora/7f40febb-3680-55a1-bc08-643cb0766ca0/scratchpad/<your-name>/`. Never commit screenshots.
- Report back concisely (≤250 words): files created/changed, exports/contracts, what is verified vs not, open issues.

## Conventions (enforced in review)
- **i18n**: every user-visible string exists in BOTH `messages/en.json` and `messages/ar.json` (natural Modern Standard Arabic, not literal translation). Never hand-edit those two big files. Write your namespace as two JSON files in the scratchpad and run `node scripts/merge-ns.mjs <namespace> <en.json> <ar.json>` — it atomically replaces that one namespace and enforces key parity. Use ICU params for any price: `pricingParams(locale)` from `lib/pricing/config` (no hardcoded numbers in copy). Currency is ILS via `formatMoney`.
- **RTL**: logical utilities only (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `border-s`, `rounded-s-*`); never `left/right/ml/mr/pl/pr` except for physical things (a canvas). Add the `u-mono` / `u-track` class on tracked/mono text that can contain Arabic (the CSS zeroes letter-spacing under RTL). Icons/arrows that imply direction must flip (use `t('common.arrow')` or `rtl:` variants). Numerals and brand names inside RTL text: wrap in `dir="ltr"` spans where needed. Never split Arabic into letters.
- **Tokens only**: Tailwind v4 theme tokens from `app/globals.css` (`bg-surface`, `text-ink`, `text-amber`, `border-border-card`, `text-signal`, `rounded-card`, `rounded-panel`, `rounded-pill`, `text-h2`, `text-display`, `py-section`, `glass`, `aura`, `spot`, `num`, z via `style={{zIndex:'var(--z-…)'}}`). **No raw hex** in components, no `box-shadow`/`shadow-*` (depth = borders, glass, radial light, translucency, hover lift). Only breakpoint is `nav:` (920px) / `max-nav:`; never `sm:/md:/lg:/xl:`. Amber is the single brand + CTA colour; the cool `signal` accent is ONLY for automation/AI/data visuals; pillar tints (`pillar-web/auto/soft`) are subtle.
- **Server components by default.** `'use client'` only on islands that need interaction. Keep client islands small; pass pre-translated strings/props down from server parents where practical (don't ship the whole message catalogue to the client — client islands may use `useTranslations` with a narrow namespace; the orchestrator will later scope `NextIntlClientProvider` messages).
- **Primitives available** (`components/motion/*`, `lib/hooks/*`): `Reveal`, `WordReveal`, `Magnetic`, `Parallax`, `TiltCard`, `Spotlight`, `CursorAura` (already mounted in layout), `CountUp` (serialisable props: value, locale, Intl options), `KineticHeadline`, `useScrollScene(scopeRef, ({gsap, ScrollTrigger, root}) => …)` (lazy GSAP), `usePointerFine`, `useFocusTrap`, `useScrollLock`, `LenisProvider` (already mounted). UI: `Container`, `SectionHeader`, `PageIntro`, `AmberBand`, `ArrowButton`, `ArrowLink`, `Chip`, `FAQAccordion`, `SiteImage`. Every effect must respect `prefers-reduced-motion`; pointer effects only with a fine pointer.
- **Honesty**: no fabricated metrics, testimonials, clients, partnerships, certifications, awards. Case studies are only `CASES` in `lib/site.ts` (4 real client domains). Estimates/ROI are labelled "indicative, not a quotation". Never pretend email/DB works when unconfigured.
- **Accessibility**: semantic landmarks/headings (one h1/page), labels for every control, visible focus (global style exists), `aria-live` for dynamic results, keyboard-only operable, contrast ≥ 4.5:1, touch targets ≥ 44px, no information by colour alone. Decorative layers `aria-hidden`.
- **Quality**: strict TS (no `any`), small modules, no dead code, no console.log, no inline `<style>` or inline raw colours (CSS `var(--color-*)` or Tailwind tokens). Clean up all listeners/animations/GPU resources on unmount.
- **Prices/taxonomy**: pricing comes only from `lib/pricing/config.ts`. One services taxonomy = the 3 pillars (Websites · Automation & AI agents · Custom software). One process = Discovery → Planning → Development → Deployment → Support (`process` namespace `s1..s5`).
